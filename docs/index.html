Yarncueについて、
よくある質問

Yarncueでは何を管理できますか？

作品、毛糸、パターン、制作の進捗やメモをまとめて管理できます。

初心者でも使えますか？

もちろんです。最初の作品から、必要な情報を自分のペースで残せます。

かぎ針編みと棒針編みの両方に使えますか？

はい。どちらの作品にも、使った糸、針、段数、パターン、メモを記録できます。

次に編む一目を、
もっと楽しみにしよう。

Yarncueと一緒に、あなたの編み物の時間を育てませんか。

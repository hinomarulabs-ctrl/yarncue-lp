Yarncue 可以管理什麼？

作品、毛線、圖案、進度和筆記，都可以放在一個地方。

初學者也能使用嗎？

當然可以。從第一件作品開始，只記錄你需要的資訊。

支援棒針和鉤針嗎？

支援。兩種編織都可以記錄行數、圈數和筆記。
